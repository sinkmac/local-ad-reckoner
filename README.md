# Local Ad Reckoner

A free, ungated, UK-first advertising second-opinion tool for small business owner-operators.

Core verb: not get had.

## Build

```bash
npm install
npm run check
npm run build
```

## Framework

- SvelteKit
- @sveltejs/adapter-netlify
- Node 20 on Netlify
- Static benchmark data from `src/lib/data/benchmarks.json`

## Launch blockers before custom domain

- Domain decision and registration on IONOS
- Human verification of benchmark figures
- Luma disclosure copy approval
